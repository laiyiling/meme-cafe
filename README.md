# ☕ 迷因咖啡館 (Meme Cafe)

> **「今天的困頓，需要哪杯特調？」**  
> 一個專為現代上班族與學生打造的輕量化 Web App，根據你當下的精神狀態，調製出專屬的迷因咖啡與扎心金句卡片！

---

## 💡 專案簡介

**迷因咖啡館 (Meme Cafe)** 是一個結合幽默感、互動性與社群分享價值的單頁應用程式 (SPA)。使用者只需選擇當前的心情與毒舌指數，系統便會透過趣味動畫調製出一杯專屬的「迷因特調」，並支援一鍵將結果卡片匯出為 PNG 圖片，方便分享至社群平台。

---

## 🚀 核心功能

* **📋 心情點餐機**：提供 4 種常見的精神狀態選項（焦慮、靈魂抽離、腦幹發平、怒火中燒）。
* **🌶️ 毒舌指數調整**：可切換微辣（⭐）、中辣（⭐⭐）、大辣（⭐⭐⭐），獲取不同辛辣程度的迷因金句。
* **☕ 趣味調製動畫**：動態進度條與輪播載入文案，增添互動趣味。
* **📸 迷因卡片匯出**：整合 `html2canvas` 套件，可將特調卡片一鍵下載為高畫質 PNG 圖片。
* **🔄 即時重新測試**：提供「再一杯」功能，隨時更換心情重新調製。

---

## 🛠️ 技術架構

* **Front-end**: HTML5, JavaScript (ES6+)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/) (透過 CDN 引進)
* **Libraries**: 
  * [html2canvas](https://html2canvas.hertzen.com/) - 用於卡片繪製與導出圖片
  * Google Fonts (`Noto Sans TC`) - 中文字體優化
* **Deployment**: [GitHub Pages](https://pages.github.com/) 免費靜態網站託管

## 📄 需求規格 

### 使用者流程 (User Flow)
| 階段 | 步驟名稱 | 核心動作與內容 |
| :--- | :--- | :--- |
| **01** | **進入網站** | 開載頁面並初始化應用程式 |
| **02** | **[步驟一：點餐]** | • 選擇精神狀態<br>• 選擇毒舌指數 |
| **03** | **[步驟二：調製動畫]** | • 視覺進度條<br>• 搞笑進度文字 |
| **04** | **[步驟三：取得特調卡片]** | • 咖啡名稱<br>• 專屬迷因金句<br>• 下載為 PNG 圖片 |
| **05** | **[下載 / 再一杯]** | • 下載卡片至裝置<br>• 重新點餐體驗 |

### 數據結構規範
* **情緒對應資料**：
  * `anxious`：焦慮過載濃縮 Espresso / 待辦事項山崩美式
  * `drained`：靈魂出竅特調歐蕾 / 原地下班燕麥拿鐵
  * `empty`：腦袋空空清晨美式 / 我是誰我在哪特調
  * `mad`：怒火中燒雙倍特濃 / 需求逼人氣泡美式
